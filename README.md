# 🏡 หมู่บ้านอัลกอริทึม — Algo Village

เกม 3 มิติเล็ก ๆ สำหรับสอนเด็กเรื่อง **Algorithm & Data Structure** สร้างด้วย
[Three.js](https://threejs.org) + 3D asset จาก [polyfork.dev](https://polyfork.dev/)
(หุ่นยนต์ ถังไม้ กล่อง เหรียญ ต้นไม้ — เป็น parametric asset ที่เรียกผ่าน CDN ตรง ๆ)

## ▶️ วิธีเล่น

ต้องเสิร์ฟผ่าน HTTP เพราะใช้ ES module (เปิด file:// ตรง ๆ ไม่ได้):

```bash
cd GameForAlgorithm
python3 -m http.server 8420
# แล้วเปิด http://localhost:8420
```

## 🎯 ภารกิจทั้ง 3

| ภารกิจ | สอนอะไร | กติกา |
|---|---|---|
| 🛢️ เรียงถังให้เป็นระเบียบ | **Sorting / Bubble Sort** — compare, swap, algorithm คือขั้นตอนที่ชัดเจน | คลิกถัง 2 ใบเพื่อสลับ เรียง 1→5 ให้สลับน้อยครั้งที่สุด (นับจากจำนวน "วงจร" ของ permutation) กดปุ่มให้หุ่นยนต์สาธิต Bubble Sort ทีละขั้นได้ |
| 🗼 หอคอยฮานอย | **Stack (LIFO) / Recursion** | ย้ายหอคอย 4 ชั้นจากเสา A ไป C — ยกได้เฉพาะใบบนสุด (กฎ Stack) และใบใหญ่วางบนใบเล็กไม่ได้ จำนวนก้าวน้อยสุด = 2ⁿ−1 = 15 ปุ่ม "ดูเฉลย" รัน recursive solution |
| 🧭 ตามหาเส้นทางเก็บเหรียญ | **BFS / Queue (FIFO) / Shortest path** | คลิกช่องบนกริด ดูคลื่น BFS สำรวจ (ส้ม = รอในคิว, ฟ้า = สำรวจแล้ว, เหลือง = เส้นทางสั้นสุด) แล้วหุ่นยนต์เดินไปเก็บเหรียญให้ครบ 3 เหรียญ |

## 🛠️ โครงสร้าง

ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว (prototype):
- Three.js + OrbitControls จาก unpkg ผ่าน importmap
- Asset จาก `https://polyfork.dev/cdn/<id>.mjs` — `createAsset({knobs})` ได้ `THREE.Group` ทันที ไม่ต้องโหลดเดอร์
- Tween/เสียง/คอนเฟตติ เขียนเองแบบมินิมอล ไม่มี dependency อื่น
- `window.__algo` คือ debug hook สำหรับทดสอบอัตโนมัติ (มี `probe(x,y)` ไว้ดูว่าคลิกโดนวัตถุอะไรก่อน)
- ถังทุกใบมี hitbox ทรงกระบอกโปร่งใสครอบ เพราะโมเดลถังของ polyfork ป่องเอว (ปากบนแคบกว่าเส้นผ่านศูนย์กลาง max) ทำให้รังสีคลิกกลางลำตัวลอดข้ามขอบไปโดนเสาใต้ถังได้

## 🧪 ทดสอบอัตโนมัติ

`tests/test-hanoi.mjs` คือ regression test ภารกิจหอคอยฮานอย (12 ข้อ: กติกา Stack, ทิศทางกติกาใบใหญ่บนใบเล็ก, วางโดยคลิกตัวถังบนเสาปลายทาง, toggle ยกเลิก, เฉลย recursive จบถูกต้องทั้งข้อมูลและภาพ) รันด้วย playwright (ใช้ Edge ของระบบ):

```bash
cd tests && npm i playwright && node run-hanoi.mjs   # มี retry กันอาการ launch ค้าง
```
